Current state of main.py:
The application has this object-storage line in __init__():

self.document_objects = []

This list is intended to store text, barcode, image, and other document objects.

Important current limitation:
The application currently draws text and barcode objects directly onto the Tkinter canvas. The draw_page() method starts with:

self.canvas.delete("all")

Because of this, any objects added directly to the canvas disappear when:
- Zooming in
- Zooming out
- Fitting the page
- Applying a template
- Redrawing the page

Suggested object formats:

Text object:

{
    "type": "text",
    "text": "Sample Label",
    "x": 45,
    "y": 150,
    "font": ("Arial", 12),
    "fill": "#222222"
}

Barcode object:

{
    "type": "barcode",
    "x": 45,
    "y": 200
}

Coordinates should be stored in unscaled page coordinates. The draw_document_objects() method should multiply coordinates by:

self.dpi * self.zoom

before drawing them on the canvas.
